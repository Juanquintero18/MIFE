# README - Proyecto Web MIFE
Descripción del proyecto

Desarrollar el sitio web oficial de MIFE (Miscelánea Integral Futurista Electrónica).

MIFE es una pequeña empresa dedicada al desarrollo, fabricación y comercialización de soluciones electrónicas, sistemas embebidos, dispositivos con microcontroladores, automatización, domótica y productos tecnológicos personalizados.

El objetivo principal del sitio web es presentar la empresa de forma profesional, mostrar sus productos y facilitar el contacto con clientes interesados tanto en productos existentes como en desarrollos personalizados.

Objetivos

El sitio web debe:

Presentar la identidad de la empresa.
Explicar claramente qué hace MIFE.
Mostrar los servicios ofrecidos.
Mostrar un catálogo de productos desarrollados.
Permitir que un cliente solicite un desarrollo personalizado.
Facilitar el contacto mediante correo electrónico y WhatsApp.
Tener una estructura escalable para futuras funcionalidades.
Público objetivo
Personas interesadas en electrónica.
Empresas que requieran soluciones electrónicas.
Instituciones educativas.
Clientes interesados en automatización.
Clientes interesados en domótica.
Personas que necesiten dispositivos personalizados con microcontroladores.
Arquitectura del sitio
Página de inicio

La página principal será la carta de presentación de la empresa.

Debe incluir:

Hero principal
Nombre de la empresa.
Breve descripción.
Mensaje que transmita innovación y tecnología.
Botón para conocer los servicios.
Botón para contactar.
Sección "Quiénes somos"

Explicar:

Historia de la empresa.
Misión.
Visión.
Valores.

Debe transmitir confianza y profesionalismo.

Sección "¿Qué hacemos?"

Explicar claramente que MIFE desarrolla:

Productos electrónicos.
Sistemas con microcontroladores.
Soluciones IoT.
Automatización.
Domótica.
Desarrollo de hardware personalizado.
Desarrollo de prototipos.
Equipo de trabajo

Mostrar una fotografía grupal del equipo.

Debe existir un espacio preparado para reemplazar posteriormente la imagen definitiva.

Llamado a la acción

Una sección invitando al usuario a:

conocer los servicios
solicitar un proyecto
comunicarse con la empresa
Header

El encabezado debe contener únicamente:

Inicio (opcional si el logo dirige al inicio)
Nosotros
Servicios
Contacto

Debe permanecer visible mientras el usuario navega (sticky header).

Servicios

Al ingresar a Servicios deben aparecer dos opciones principales.

1. Catálogo

Contendrá productos ya desarrollados por la empresa.

Por ahora únicamente crear la estructura.

Cada producto podrá contener posteriormente:

Imagen
Nombre
Descripción
Tecnologías utilizadas
Estado
Botón para solicitar información

No agregar productos ficticios.

Crear solamente la estructura para futuras incorporaciones.

2. Requerimientos

Esta sección permitirá que un cliente solicite un desarrollo personalizado.

Debe incluir un texto introductorio indicando que MIFE desarrolla soluciones a la medida.

Debe existir un formulario con campos como:

Nombre
Empresa (opcional)
Correo
Teléfono
Tipo de proyecto
Descripción del requerimiento

Además deben existir botones visibles para:

Enviar correo
Abrir conversación por WhatsApp

Diseñar esta sección pensando en convertir visitantes en clientes potenciales.

Contacto

Debe contener:

Dirección (editable posteriormente)
Correo electrónico
Teléfono
WhatsApp
Horario de atención
Mapa (espacio preparado para integración futura)

No usar datos reales; dejar marcadores de posición claramente identificados.

Footer

El pie de página debe contener:

Política de privacidad
Política de cookies
Aviso legal

Además:

Logo de MIFE
Derechos reservados
Año actual
Redes sociales (estructura preparada para agregarlas posteriormente)
